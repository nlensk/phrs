# Code
This directory contains code that I created for analyzing phage resistomes.

__ARO_library:__ Creates a dictionary for AROS. <br>
__TEMseqAnalysis:__ Outputs sequence lengths in a file. <br>
__check_ids:__ Checks if the ids in a pair of nucleotide and protein files overlap. <br>
__genome_string:__ Creates a dictionary where the headers are the keys and the sequences are the values. <br>
__hit_position:__ Analyzes the location of blast hits. <br>
__reverseCompliment:__ Takes a sequence and outputs its reverse compliment counterpart <br>
__geneticCode:__ Takes a nucleotide sequence and translates it into a protein sequence
